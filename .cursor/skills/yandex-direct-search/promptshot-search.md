## Launch gate — расход

Пополнение и включение только если:

1. миграции 196/197/198 на проде;
2. живой MP: у смоука `yandex_conversion_sent_at` не null (не только JS `purchase`);
3. UTM/`yclid` доезжают до visitor и платежа;
4. есть прогноз CPC по фразам или явный допуск learning loss.

Stop-loss: фраза 82 ₽ без покупки; кампания 164 ₽ без покупки; 30 кликов без успешной генерации.

Масштаб (резерв / следующие 30к): ≥5 первых плательщиков, CAC ≤ актуального `CAC_max`, mature D30, шаг бюджета 20–30% не чаще раза в 3 дня.
