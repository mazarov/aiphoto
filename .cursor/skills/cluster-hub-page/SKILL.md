## Очередь

1. Открыть [queue.md](queue.md), сортировка уже по визитам ↓.
2. Взять первую строку, где «Готово» пусто. Не перескакивать на более мёртвую страницу.
3. `/osen` и `/v-forme` уже `да`. Их URL не менять.
4. После выката хаба поставить в этой строке `да`. Не отмечать готовность до кода и тестов.

## Вход

Страница берётся из очереди. Дальше нужны оба среза Яндекса и тег ленты. Нет файла — сначала `@webmaster-page-collect`, не выдумывать ключи и позиции. Готовые срезы лежат в `webmaster-page-collect/inbox/<slug>/`.

1. **Позиции, чтобы не сломать полку.** Яндекс Вебмастер → Эффективность → Мониторинг запросов, фильтр по текущему URL страницы. Нужны запрос, показы, клики, CTR, средняя позиция. Это не Вордстат: у Вордстата нет позиций. Сайтвайд MCP `search_queries` не подставлять — там нет связки запрос→URL. `search_urls` только проверяет, что URL жив.
2. **Спрос для слотов.** Яндекс Вебмастер → Подбор запросов и анализ рынка (Wordcraft, колонки `query`, `cluster`, `clicks`, `demand`). Это разбор спроса, не позиции. Выгрузка XLSX. В интерфейс Вордстата и Вебмастера агент сам не логинится: капча и сессия ненадёжны, рабочий вход — файл пользователя.
3. **Тег ленты** для карусели. Без тега — стоп.

Не трогать: `/ii-fotosessiya/*`, карточку `/p/[slug]`, оплату.

## URL с `/s-mashinoy`

Для каждой неготовой строки очереди, начиная с `https://promptshot.ru/s-mashinoy`:

- Новый каноникал: `https://promptshot.ru/promty-dlya-foto` + старый path. Пример: `/s-mashinoy` → `/promty-dlya-foto/s-mashinoy`.
- Точный 301 со старого path на новый хаб.
- Позиции снимать со **старого** URL: полка ещё там. Слоты и тег ленты не меняются из-за нового path.
- Уже готовые `/osen` и `/v-forme` остаются на коротких URL.
- Чипы остаются на новом хабе через query, без второго object-тега.

## Слоты страницы

Один запрос — один видимый заголовок. Одна лемма не живёт в H1 **и** H2.

| Слот | Что берёт | Что не берёт |
|---|---|---|
| Title | sitelink / exact коммерческий + объём (`800+`) | повтор H1 слово в слово |
| H1 | широкий владелец кластера | sitelink-exact, бренд модели |
| Hero intro | соседний синоним + объём + действие | ключ H2, «открой другую страницу» |
| Карусель | только тег кластера, `sort=new`, `ctaLabel=null` | лента главной, текущий `?filter` |
| Explorer H2 + абзац | самый жирный **оставшийся** ВЧ | ключ H1 / intro, Nano Banana / Gemini / ChatGPT, URL-хвосты |
| HowTo | служебный синоним hero | exact sitelink |
| FAQ | один exact sitelink + рабочие вопросы | «перейди на другую страницу», «не описывай лицо» |
| Чипы | НЧ с карточками в базе | новый L2, чип без выдачи |

НЧ и сюжеты (`в машине`, `в студии`, `весенние`) — чипы `?audience=` / `?style=` / `?object=` / `?occasion=`. Canonical остаётся хаб.

Выкинуть с хаба: `seoTextBlocks`, «Популярные сценарии», mid-page generate-CTA, `popularLinks` как свалка ключей.

## Фаза 1 — карта слотов

1. Прочитать кластер. Выкинуть бренды нейросетей, `habr.com` / `vc.ru` / path-хвосты, мусор.
2. Считать позиции Вебмастера **только по этому URL**. Свести с кластером: demand vs «уже ранжируемся / слабо / нет».
3. Сгруппировать: широкий каталог / фото-синоним / photoshoot-синоним / sitelink-exact / сюжеты.
4. Слоты сверять с полкой, не только с Wordstat:

| Полка на этом URL | Что делать |
|---|---|
| Топ-3 / уже в Title или H1 | Оставить в том слоте. Не тащить в H2 «для плотности» |
| Позиция 8+ или нет в срезе, но demand в кластере высокий | Кандидат в свободный слот (обычно explorer H2) |
| Ранжируется здесь, но владелец — другой URL | Не сажать в H1/Title |
| Есть в Вебмастере, нет в кластере | Не игнорировать: страница уже за это цепляется — решить, какой слот держит |

5. Показать таблицу **до кода**:

```markdown
## Карта слотов — {URL}
| Слот | Запрос | demand / clicks | позиция Вебмастера | Почему |
| Title | | | | |
| H1 | | | | |
| Hero intro | | | | не ключ H2 |
| Explorer H2 | | | | не ключ H1/intro; обычно слабая/пустая полка |
| HowTo | | | | |
| FAQ exact | | | | один |
| Чипы | | | | только если есть карточки |
| Выкинуть | | | | бренд / чужой URL / спам |
```

6. Черновик copy: Title, H1, intro, `explorerTitle`, `explorerIntro` (1 абзац), HowTo, 4–7 FAQ.
7. Спросить: «Берём эту карту?» Без «ок / делай» — не внедрять.

Критерий как у пар: человек видит hero (H1 + свои фото + счётчик), ниже — H2 про другой запрос, поле поиска и карточки. Тексты не повторяют одну фразу.
