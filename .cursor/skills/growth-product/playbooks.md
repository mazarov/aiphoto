# Playbooks: YouTube / Facebook / TikTok → PromptShot

Читай, когда нужна калибровка «как думала бы платформа», а не общий workflow.

## YouTube

- **Watch time > views.** Клики без потребления — налог на доверие. Аналог: не «открыл карточку», а «скопировал / сгенерировал / повторил».
- **Двусторонний рынок.** Зритель без свежего supply уходит; автор без просмотров перестаёт заливать. Аналог: SEO-страницы без действия и генерации без каталога, который хочется повторить.
- **CTR сниппета — вход, не продукт.** Высокий поисковый CTR при низком action rate = плохой интент или обманчивый сниппет.
- **Рекомендации как рост.** После первого успеха следующий объект очевиден: соседняя карточка, «повторить», тот же стиль.

Не копировать: PromptShot не видео. «Время на сайте» — плохая north star, если человек ушёл копировать промт в другую модель — это может быть успешный aha.

## Facebook

- **Активация = критическая масса ценности.** Не tutorial. Первая удачная генерация или первый промт, который сработал снаружи.
- **DAU/MAU = привычка.** Рост MAU при падении DAU/MAU — мёртвый трафик.
- **Friction kill.** Аккаунт, paywall, загрузка фото, выбор модели до core action режут активацию. Платить после wow.
- **Re-entry** только если в продукте уже есть новая ценность. Пустые «вернись» сжигают канал.
- **Граф.** У PromptShot слабый социальный граф. Не строить «инвайт друзей» главным loop, пока нет артефакта, которым гордятся.

Урок: leading indicator активации ищут экспериментами. Какие действия в день 0 предсказывают D7.

## TikTok

- **Time-to-wow в секундах.** Карточка и генерация дают картинку/промт сразу, без подписки.
- **Completion / rewatch / share** важнее follow. Аналог: досмотр примера, повтор генерации, копирование, шаринг результата.
- **Шанс новому supply.** Новые карточки не хоронить forever-sort=popular, иначе каталог гниёт.
- **Remix.** Чужой промт → правка → новая генерация → новая карточка.
- **Низкий cost of trying.** Text-only и «повторить» ближе к TikTok, чем тяжёлый photo pipeline. Photo-to-prompt — отдельный high-intent вход, не единственный.

Не копировать: бесконечный скролл без действия = views без watch time. Лента должна конвертировать в copy/generate.

## Какой плейбук

| Симптом | Чей плейбук | Первый ход |
|---|---|---|
| Трафик есть, действия нет | YouTube | Интент сниппета, aha на карточке, session quality |
| Регистрируются и пропадают | Facebook | Time-to-first-success, убрать friction, leading indicator D7 |
| Контент есть, его не находят | TikTok + YouTube | Дистрибуция новых карточек, related, «повторить» |
| Генерации есть, возврата нет | Facebook + YouTube | История, кредиты как топливо, новые стили |
| Supply тонкий или мусорный | YouTube marketplace | Качество ingest, UGC, не плодить SEO-страницы в пустоту |
| Просят «как у TikTok» | TikTok только если time-to-wow уже < 10с | Иначе сначала Facebook-активация |
| Платный трафик без aha | YouTube + Facebook | Не масштабировать Direct, чинить посадочную и путь до первой генерации |

## Метрическое дерево

```
North star (ценность / неделю)
├── новые, дошедшие до aha
│   ├── qualified discovery (search, listing, SEO, Direct, tab)
│   ├── time-to-first-success
│   └── fail/friction до aha
├── вернувшиеся
│   ├── D1 / D7
│   ├── generations или copy на возвращающейся сессии
│   └── причина возврата (история, тренд, кредиты, SEO)
└── петля supply
    ├── новые карточки, которые получают действия
    ├── UGC publish rate
    └── доля карточек-зомби (показы без action)
```

## Классы экспериментов

1. **Aha faster** — убрать шаг, показать результат раньше, guest success.
2. **Better match** — интент, поиск, related, ranking новых vs популярных.
3. **More reason to return** — история, кредиты, тренды, незавершённая генерация.
4. **Supply quality** — пайплайн, модерация, UGC.
5. **Monetize after value** — paywall после успеха, не вместо него.

Класс 5 раньше 1–2 — не рост, а налог на неактивированных.
