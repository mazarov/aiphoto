## 2. Один URL — один ключ

```
URL: /
Тип: листинг-хаб
Ключевой запрос: «промты для фото»
Синонимы и хвосты: промт для фото, промты, промты для ии, промты для нейросети,
  готовые промты для фото, промты для ии фотосессии
Сюда не входит: пары / семья / ДР / девушка / мужчина; обработка / качество / оживление;
  фото → промт; сделать фото ИИ; видео
```

Порядок блоков — как на странице (скрины 27.08): hero → каталог → галерея (H2 + intro) → HowTo → FAQ. Модели, тарифы, отзывы, «что ещё умеет», редактор на главную не копируем.

## 4. Чего не делать

- Не класть второй head в Title.  
- Не переносить на `/` инструменты, отзывы, модели, тарифы, «что ещё умеет».  
- Не оптимизировать главную под обработку / качество / оживление / видео.  
- Не обещать бесплатную генерацию. Бесплатно — копирование промта.  
- Не писать «промпт» в RU SEO.  
- Не тащить ChatGPT / Gemini / Midjourney в Title.
