# 16-08 Homepage examples explorer

Главная `/` показывает ленту популярных промтов вместо hero-поиска и плиток категорий.

## Ставка

SEO-гость кластера «промты для фото» сразу видит карточки. Чип = фильтр категории на месте + живая ссылка на L1.

## Поведение

- Сетка: `fetchRouteCards({ sort: "popular", limit: 16 })`, клик открывает модалку карточки. «Повторить» нет.
- Чипы: «Все» + топ Wordstat без «На паспорт». Хвост категорий, включая паспорт, — `sr-only` ссылки для краулера, без кнопки «Ещё».
- Поиск на месте через `/api/search`. CTA: категория → L1, поиск → `/search`, дефолт → `/catalog`.
- Текущие title / H1 / intro / FAQ не менялись. Новые тексты только в блоке (`examplesTitle`, `examplesIntro`) с расширителями GPT / Nano Banana / Gemini.

## Не трогаем

`/generaciya-foto` explorer, `/catalog`, шапка, сайдбар, `get_homepage_sections` для счётчиков / OG / JSON-LD `hasPart`.
