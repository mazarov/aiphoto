## 2. Решение

Три страницы в секции `/generaciya/`, разделение по **объекту** и **режиму**:

| URL | Режим | Кластер-владелец | Статус |
|---|---|---|---|
| `/generaciya/foto-po-opisaniyu` | только текст | фото по описанию / по тексту / по промту | 301 с `/generaciya-foto` |
| `/generaciya/kartinka-po-opisaniyu` | только текст | картинка / изображение по описанию / по тексту | новая |
| `/generaciya/po-foto` | со своим фото | «сделать фото ии по своему фото», семья «по фото», инструменты редактирования | новая, родитель 22 сценариев |
| `/generaciya/po-foto/<slug>` | со своим фото | 22 сценария без изменений | 301 с `/generaciya-foto/<slug>` |
| `/generaciya` | — | — | 301 на `foto-po-opisaniyu` |

Принято пользователем: переезд хаба на URL с точным вхождением и вынос фото-режима на отдельную страницу — одной волной (вариант 2), чтобы не делать вторую миграцию детей.

## 5. Владение — что куда

- фото* · по промту → `foto-po-opisaniyu`
- картинка* · изображение* → `kartinka-po-opisaniyu`
- по фото · со своим лицом · изменить / редактор фото → `po-foto`
- «промт для создания фото» (140 показов, 0 кликов на хабе) → владелец `/` (каталог), отдельная задача
- «текст в картинку / в изображение» → только FAQ kartinka
- «добавить / написать / наложить текст», «найти изображение» → никуда

## 6. Реализация

- SSOT путей: `landing/src/lib/generaciya-foto-routes.ts` (`GENERACIYA_*_PATH`, `getGeneraciyaFotoScenarioPath`, `generaciyaLegacyRedirectPath`, `isGeneraciyaHubPath`).
- 301: `landing/src/middleware.ts` — до CORS/slug-редиректов; query отбрасывается (служебные параметры были мусором индекса).
- Страницы: `landing/src/app/generaciya/{foto-po-opisaniyu,kartinka-po-opisaniyu,po-foto}/page.tsx`, `po-foto/[scenario]/page.tsx` (перенесён). Общий hero `GeneraciyaHubHero`, блок `GeneraciyaHowItWorks`, данные/JSON-LD `generaciya-hub-data.ts`.
- Стартер: `GeneraciyaFotoStarter` получил `modes` и `ctaLabel`; с одним режимом селектор не рендерится.
- Copy: `generaciya-foto-seo-copy.ts` (текст-хаб + `GENERACIYA_PO_FOTO_*` + `GENERACIYA_MODE_LINKS`, FAQ разведены `pickFaq`), `kartinka-po-opisaniyu-seo-copy.ts`.
- Внутренние ссылки переведены: сайдбар («Фото по описанию»), главная destinations, кластеры (`den-rozhdeniya`, `par`, `devushki`, `muzhchiny`, `ii-fotosessii` → `po-foto`), `foto-v-promt`, `trends`, pricing, письма, `llms.txt`, sitemap, watchlist paths.
