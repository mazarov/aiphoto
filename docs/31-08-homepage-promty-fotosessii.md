# 31-08 Кластер «промты для ИИ фотосессии» → `/` и L1

> **Дата:** 2026-08-31
> **Статус:** в коде
> **Ветка:** `feature/31-08-homepage-promty-fotosessii`
> **Роль:** `@senior-seo-strategist-ru`

«Промты для ии фотосессии» снова на хабе каталога `/` и дочерних L1. `/ii-fotosessiya` остаётся глаголом «собрать серию по фото». Старый `/promty-dlya-ii-fotosessii` не оживляем — 301 на глагол.

---

## 1. Один URL — один ключ

| URL | Тип | Ключ | Не берёт |
|---|---|---|---|
| `/` | каталог промтов | промты для фото; complement — промты для ии фотосессии | сделать ИИ фотосессию; L1-аудитории в Title |
| `/promty-dlya-foto-devushki` | L1 кадра | промты для фото девушки | ИИ-фотосессия в Title/H1 |
| `/promty-dlya-foto-muzhchiny` | L1 кадра | промты для фото мужчины | …мужские в Title/H1 |
| `/promty-dlya-foto-par` | L1 кадра | промты для фото пар | …пары в Title/H1 |
| `/ii-fotosessiya` | инструмент серии | ии фотосессия по фото | промты для ии фотосессии в Title/H1 |

L1 держат хвост кластера в **H2 + FAQ**, не в Title/H1.

---

## 3. L1

Title/H1 не менять. `popularLinks` «ИИ-фотосессия» → `/ii-fotosessiya/{slug}` — глагол.

| URL | H2 / FAQ |
|---|---|
| `/promty-dlya-foto-devushki` | Промты для ИИ фотосессии женские |
| `/promty-dlya-foto-muzhchiny` | Промты для ИИ фотосессии мужские |
| `/promty-dlya-foto-par` | Промты для ИИ фотосессии пары |
| `/promty-dlya-semejnogo-foto` | Промты для ИИ фотосессии семейные |
| `/promty-dlya-detskih-foto` | Промты для ИИ фотосессии детские |
| `/sobytiya/den-rozhdeniya` | Промты для ИИ фотосессии на день рождения |

Дальше тем же шаблоном: зима, новый год, студия, форма.

---

## 4. Антиканнибал

- `/ii-fotosessiya`: без «промты для ии фотосессии» в Title/H1.
- `/`: не отдавать этот ключ FAQ-ом на глагольный хаб.
- L1: «серию собирайте в ИИ фотосессии» — только CTA серии, не владение промт-запросом.

---

## 5. Как понять, что сработало

Через 14 дней в Вебмастере:

- «промты для ии фотосессии» — CTR ≥ 12% или позиция ≤ 5;
- «промты для фото» не проседает по кликам;
- «промты для ии фотосессии женские» растут на `/promty-dlya-foto-devushki`, не на `/ii-fotosessiya/zhenskie`.
