## 1. Один URL — один ключ

| URL | Тип | Ключ | Не берёт |
|---|---|---|---|
| `/` | каталог промтов | промты для фото; complement — промты для ии фотосессии; вторичный кластер в каталоге/FAQ — промты для нано банана | сделать ИИ фотосессию; L1-аудитории в Title; нано банана в Title/H1/Description |
| `/promty-dlya-foto-devushki` | L1 кадра | промты для фото девушки; complement — ИИ фотосессии | сделать ИИ фотосессию |
| `/promty-dlya-foto-muzhchiny` | L1 кадра | промты для фото мужчины; complement — ИИ фотосессии | сделать ИИ фотосессию |
| `/promty-dlya-foto-par` | L1 кадра | промты для фото пар; complement — ИИ фотосессии | сделать ИИ фотосессию |
| `/ii-fotosessiya` | инструмент серии | ии фотосессия по фото | промты для ии фотосессии в Title/H1 |

L1 как `/`: ключ кадра первым в Title/H1, complement «и ИИ фотосессии». Точный хвост («женские» / «парные») — Description + H2 + FAQ. **L2-комбо** (напр. `/promty-dlya-foto-devushki/studiynoe`) — тот же complement через `prompt-listing-fotosessii-seo.ts`; ручные long-tail (ДР девушке) без изменений.

| H1 | `Промты для фото` + accent `в ИИ` |

## 3. L1

Title / H1 / Description — как на `/`: кадр + «и ИИ фотосессии». `popularLinks` «ИИ-фотосессия» → `/ii-fotosessiya/{slug}` — глагол.

| URL | Title / H1 | Description / H2 |
|---|---|---|
| `/promty-dlya-foto-devushki` | Промты для фото девушки и ИИ фотосессии | промты для ИИ фотосессии женские |
| `/promty-dlya-foto-muzhchiny` | Промты для фото мужчины и ИИ фотосессии | промты для ИИ фотосессии мужские |
| `/promty-dlya-foto-par` | Промты для фото пар и ИИ фотосессии | промты для ИИ фотосессии парные |

| `/promty-dlya-detskih-foto` | Промты для детских фото и ИИ фотосессии | промты для ИИ фотосессии детские |

Дальше тем же шаблоном: зима, новый год, студия, форма.

---

## 4. Антиканнибал

- `/ii-fotosessiya`: без «промты для ии фотосессии» в Title/H1.
- `/`: не отдавать этот ключ FAQ-ом на глагольный хаб.
- L1: «серию собирайте в ИИ фотосессии» — только CTA серии, не владение промт-запросом.

---

## 5. Как понять, что сработало

Через 14 дней в Вебмастере:

- «промты для ии фотосессии» — CTR ≥ 12% или позиция ≤ 5;
- «промты для фото» не проседает по кликам;
- «промты для ии фотосессии женские» растут на `/promty-dlya-foto-devushki`, не на `/ii-fotosessiya/zhenskie`.
