## 3. Продукт

- Порядок: hero + стартер → модели → примеры с тематическими чипами →
  инструменты редактирования → HowTo → доступ из России → тарифы → FAQ.
- Отдельный блок тем удалён: он дублировал фильтры примеров и делал лишние
  серверные запросы.
- Синтетические отзывы с посаженными ключами удалены. Возвращать отзывы можно
  только с реальным источником.
- «Что ещё умеет PromptShot» удалён из конверсионной части страницы.
- Отдельный блок «Nano Banana в России» закрывает без VPN, русский интерфейс,
  оплату в рублях и честно поясняет, что PromptShot — не Google AI Studio.
- Модели в витрине — только семейство Nano Banana (`isNanoBananaFamilyModel`).
- На входе страницы `preferModelId(gemini-2.5-flash-image)` — док не открывается.
- `isGenerateDockSeoPagePath` включает `/nano-banana` (FAB прячется, пока виден стартер).
- `/nano-banana` не показывается в сайдбаре и меню инструментов главной.
  Индексируемая перелинковка идёт из блока «Модели ИИ для генерации фото»
  на `/generaciya-foto`: все карточки семейства Nano Banana ведут на хаб.

## 5. Кириллическая ветка (2026-09-06)

**Ветка:** `feature/nano-banana-cyrillic-seo`

Разбор позиций (`nano banana` → `/nano-banana`) показал: demand 127–230
показов/сутки, но **позиция 0 почти каждый день** — страницы нет в выдаче по
своему главному ключу. Единственный день с позицией (03.09) дал поз. 26,
CTR 50%, 1 клик. При этом по мусорным хвостам («что такое детализация 2к в
нанабананп», «портрет пол лица мужчины и девушки нано багана») страница сидит
на поз. 4–13 — то есть индексация есть, слабая релевантность основному запросу.

Причина по выгрузкам (1 989 запросов, после чистки 1 719 / 282k clicks):

| Токен | Запросов | Clicks | Было в тексте |
|---|---|---|---|
| `nano banana` (латиница) | 1 015 | 219k | 33 |
| `нано банана` (кириллица) | 997 | **78k** | **0** |
| `нейросет` / `нейронк` / `ии` | 455 | 39,6k | 5 |
| `ru` / `ру` | 381 | 45k | 0 |
| `официальный сайт` | 68 | 10,7k | только в отрицании |

Кириллица — половина кластера и не встречалась на странице ни разу, тогда как
конкуренты, забирающие выдачу, дают её в Title: `nano-banana-pro.ru`
(360 запросов в выдаче), РБК («Как использовать **Нано Банана** (Nano Banana)»),
klerk («Nano Banana (**Нано Банана** от Гугл) для фото»).

Сделано:

- Title / H1 / Description / intro — добавлена форма «нано банана», латиница
  сохранена как основная (H1 и Title начинаются с `Nano Banana`).
- Intro — синоним «нейронка»; блок «Интерфейс на русском» — ru-интент.
- FAQ 7 → 9: «Нано банана и Nano Banana — это одно и то же?» (закрывает
  нанабанана / нано банано / нано банан) и «Есть ли официальный сайт нано
  банана на русском?» (ветка 10,7k clicks, честно: мы не сайт Google).
- Вопрос про Pro дополнен формой «нано банана про» — без создания URL.
- Тест `cyrillic branch of the cluster is covered` фиксирует покрытие.

Границы: слово «промт» на страницу не вернулось (владелец — `/`);
`/nano-banana/pro` и `/nano-banana/2` по-прежнему отложены (§4), хотя это
≈32k clicks, которые сейчас забирает `nano-banana-pro.ru`.
