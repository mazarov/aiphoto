# 20-08 — Veo 3.1 Lite

> Дата: 2026-08-20  
> Статус: код готов; выкат: worker + landing → SQL 202  
> Ветка: `feature/20-08-veo-3.1-lite`

## Цель

Третья video-модель в том же durable job «Оживить». Дефолт остаётся Grok 1.5. Veo 3.1 Lite — дешёвый ярус Google Veo.

## Контракт

| Параметр | Значение |
|---|---|
| Модель API | `veo-3.1-lite-generate-preview` |
| UI | Veo 3.1 Lite |
| Кадр | 9:16 / 16:9 |
| Длительность | 4 / 6 / 8 сек (10 сек нет — clamp в API/UI/worker) |
| Разрешение | 720p |
| Кредиты | база **15** + 0/10/20 за 4/6/8 сек → 15 / 25 / 35 |
| Источник | одно фото (parent image XOR upload) |
| Провайдер | Gemini `POST /v1beta/models/{id}:predictLongRunning` → poll operation |

`GEMINI_PROXY_BASE_URL` как у Omni. Не звать `generativelanguage.googleapis.com` напрямую, если прокси включён. Скачивание `files/*` переписывается на тот же proxy origin.

First/last frame, 1080p, extension — не в релизе.

## Выкат

1. Worker + landing
2. SQL `202` (модель появится в пикере)
3. Смоук: 4с и 8с, 9:16/16:9, resume, fail/refund

Откат: `enabled:false` у `veo-3.1-lite-generate-preview` в `video_models`.
