Соцстрока с эмодзи 📸️.

## Мета

| Поле | Текст | Лимит |
|------|--------|--------|
| Title | Сделать фото ИИ онлайн | ≤ 75 |
| H1 | Создавайте красивые ИИ-фото себя — без студии и камеры | Facee |
| Description | Онлайн сервис: сделать фото ии по описанию или снимку, сгенерировать фото ии нейросетью и создать изображение. | ≤ 132 |

В Title/description нет `best` / `#1` / `бесплатно`. «Бесплатно» — в блоках Facee.

Видимый `#seo-opisanie` снят. Ключ живёт в Title и meta description.

Стартер не добавляет свои H2/eyebrow: первый экран = Facee (H1 + соцстрока + intro + CTA). Карточки «По описанию» / «По фото» — только продуктовый вход. CTA стартера «Создать фото». Не сажаем «девушке / парное / на др», Алису, Telegram, обработку.

Не копируем чужие метрики Facee («N запусков на этой неделе», «2.5 млн / 60 млн»).
