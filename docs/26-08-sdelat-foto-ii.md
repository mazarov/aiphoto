## Мета

| Поле | Текст | Лимит |
|------|--------|--------|
| Title | Сделать фото ИИ онлайн \| нейросеть для генерации изображений \| PromptShot | ≤ 75 |
| H1 | Сделать фото ИИ онлайн | Видимый H1; «по промту/снимку» — в Description, intro, FAQ |
| Description | ИИ сделать фото по промту или своему снимку. Выберите образ, загрузите фото — генератор PromptShot без фотографа. | ≤ 132 |

В Title/description нет `best` / `#1` / `бесплатно`. «Бесплатно» — в блоках Facee.

Видимый `#seo-opisanie` снят. Ключ живёт в Title и meta description.

Стартер не добавляет свои H2/eyebrow: первый экран = H1 + intro + карусель + живая соцстрока + стартер. Карточки «Генерация по тексту» / «Генерация по фото» — только продуктовый вход. CTA стартера «Создать фото». Чип квоты на фото-карточке — компактный `N/10`. Не сажаем «девушке / парное / на др», Алису, Telegram, обработку.

Не копируем чужие метрики Facee («N запусков на этой неделе», «2.5 млн / 60 млн»).
