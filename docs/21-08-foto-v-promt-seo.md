## Зачем

Страница уже живая: 11 071 показ, 1 339 кликов, CTR 12,1% за 14.07–14.08. H1 «Фото в промт» верный. Тексты были размазаны по трём ключам, из‑за этого слабо клеился запрос, который реально кликают.

Точная «фото в промт» — 148 показов / 16 кликов. Семейство **«промт по фото»** — ~1 900 / ~420, CTR 20–50%, позиции 2–4.

30.08: How/FAQ закрывают доп. семантику того же интента — «описание фото для нейросети», «картинка в промт», «промт по изображению». Title, H1 и H2 виджета не меняли. Новой секции нет.

## Ключ страницы

```
URL: /foto-v-promt
Тип: инструмент
Ключевой запрос: «фото в промт»
Синонимы и хвосты (не Title): описание фото для нейросети, картинка в промт,
из фото в промт, фото в промпт, промт по изображению, сделать из фото промт,
создание промта по фото
Рабочий СЧ (H2 + FAQ): «промт по фото», «промт по фото онлайн»
Сюда не входит: промты для фото (/), фото по промту (/generaciya-foto),
генератор промт по картинке / image to prompt (Google, не этот заход)
```

Один URL — один ключ в Title и H1.

## Карта вхождений

| Запрос | Заголовок | Ещё | Нельзя |
|---|---|---|---|
| фото в промт | Title, H1, JSON-LD name | FAQ «Что значит…» | H2 виджета |
| промт по фото | H2 виджета | FAQ «Как сделать…», «Где сделать…»; subtitle виджета (лимит + CTA) | Title, H1 |
| промт из фото | How H2 | How step 1 («сделает из фото промт») | Title |
| промт по картинке | — | How snippet | Title, H2 виджета |
| промт по изображению | — | How snippet | Title |
| картинка в промт | — | How snippet (не lead) | Title |
| сделать из фото промт | — | How step 1 | Title, H1 |
| фото в промпт | — | 1× How snippet | Title, H1, nav |
| описание фото для нейросети | — | FAQ «Как сделать описание…» | Title, H1, H2 виджета |
| фото по промту | — | ссылка на `/generaciya-foto` | любой SEO-заголовок этой страницы |

В одном абзаце не мешать «фото в промт» и «промт по фото». Не звать в Nano Banana / ChatGPT — только PromptShot.

## Тексты в коде

**Title:** Фото в промт онлайн | PromptShot  
**H1:** Фото в промт  
**Description:** Загрузите фото и получите промт — описание сцены для нейросети. 10 разборов в сутки без регистрации, дальше 1 токен. Текст можно скопировать или сразу сгенерировать кадр.  
**Hero:** Загрузите снимок в форму ниже — сервис напишет промт.  
**H2 виджета:** Промт по фото  
**Widget lead:** 10 разборов в сутки бесплатно — без регистрации. Скопируйте промт или сразу сгенерируйте кадр.  
**How H2:** Как получить промт из фото  
**How lead:** Загрузите файл в форму на этой странице — программу ставить не нужно. Расширение понадобится, если разбираете картинку на Pinterest, Instagram или другом сайте.  
**How step 1:** сделает из фото промт  
**How snippet:** промт по картинке, промт по изображению, картинка в промт, фото в промпт (1×) — без «промт по фото» в том же абзаце  
**FAQ lead:** Перед тем как загрузить снимок  
**FAQ:** 8 вопросов — ключи в формулировках вопросов; ответы короткие, без повтора widget/how и без SEO-набивки в одном абзаце.

Полный комплект — `FOTO_V_PROMT_*` в `foto-v-promt-copy.ts`.

## Что не меняли

- URL, canonical, index
- виджет, лимиты, токены, analyze API
- CTA «Сгенерировать» → dock
- empty-state виджета («не селфи»)
- тексты `/` и `/generaciya-foto`
- Title, H1, H2 виджета (30.08)

## Как понять, что сработало

Через 14 дней в Вебмастере по `/foto-v-promt`:

- клики страницы не ниже текущих;
- «фото в промт» — позиция и CTR не хуже прежних;
- «промт по фото» CTR не падает;
- появляются показы/клики по «описание фото для нейросети» / «картинка в промт» / «промт по изображению».

Если ядро «фото в промт» просядет по позиции — откатить только description и FAQ «Что значит…», How оставить. Title и H2 виджета не откатывать: их 30.08 не меняли.
