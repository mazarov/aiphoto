# 21-08 — SEO `/foto-v-promt`: точные вхождения

> Дата: 2026-08-21  
> Статус: тексты внесены в `landing/src/lib/foto-v-promt-copy.ts`  
> Страница: `https://promptshot.ru/foto-v-promt`  
> Старое ТЗ (не править): `docs/requirements/02-06-foto-v-promt-seo-copy.md`

## Зачем

Страница уже живая: 11 071 показ, 1 339 кликов, CTR 12,1% за 14.07–14.08. H1 «Фото в промт» верный. Тексты были размазаны по трём ключам, из‑за этого слабо клеился запрос, который реально кликают.

Точная «фото в промт» — 148 показов / 16 кликов. Семейство **«промт по фото»** — ~1 900 / ~420, CTR 20–50%, позиции 2–4.

## Ключ страницы

```
URL: /foto-v-promt
Тип: инструмент
Ключевой запрос: «фото в промт»
Синонимы и хвосты (не Title): промт из фото, картинка в промт, из фото в промт, фото в промпт
Рабочий СЧ (H2 + FAQ): «промт по фото», «промт по фото онлайн»
Сюда не входит: промты для фото (/), фото по промту (/generaciya-foto),
генератор промт по картинке / image to prompt (Google, не этот заход)
```

Один URL — один ключ в Title и H1.

## Карта вхождений

| Запрос | Заголовок | Ещё | Нельзя |
|---|---|---|---|
| фото в промт | Title, H1, JSON-LD name | FAQ «Что значит…» | H2 виджета |
| промт по фото | H2 виджета | FAQ «Как сделать промт по фото?» | Title, H1 |
| промт из фото | How H2 | How step 1 | Title |
| промт по картинке | — | How snippet | Title, H2 виджета |
| картинка в промт | — | How intro | Title |
| фото в промпт | — | 1× подпись «промпт» в How | Title, H1, nav |
| фото по промту | — | ссылка на `/generaciya-foto` | любой SEO-заголовок этой страницы |

В одном абзаце не мешать «фото в промт» и «промт по фото».

## Тексты в коде

**Title:** Фото в промт онлайн | PromptShot  
**H1:** Фото в промт  
**Description:** Загрузите фото и получите промт. 10 разборов в сутки без регистрации, дальше 1 токен. Текст можно скопировать или сразу сгенерировать кадр.  
**Hero:** Загрузите снимок в форму ниже — сервис напишет промт.  
**H2 виджета:** Промт по фото  
**How H2:** Как получить промт из фото  

Полный комплект — `FOTO_V_PROMT_*` в `foto-v-promt-copy.ts`.

## Что не меняли

- URL, canonical, index
- виджет, лимиты, токены, analyze API
- CTA «Сгенерировать» → dock
- empty-state виджета («не селфи»)
- тексты `/` и `/generaciya-foto`

## Как понять, что сработало

Через 14 дней в Вебмастере по `/foto-v-promt`:

- клики страницы не ниже текущих (~42/день);
- «фото в промт» — позиция и CTR не хуже 3,8 / 10,8%;
- «промт по фото» и «промт по фото онлайн» — позиция ближе к 1–3, CTR не падает.

Если ядро «фото в промт» просядет по позиции — откатить Title, H2 виджета оставить.
