# 28-08 — Холст фотосессии по формату исходника

> Дата: 2026-08-28  
> Ветка: `feature/28-08-ai-photoshoot-aspect`  
> Статус: в работе

## Решение

Источник (parent `aspect_ratio` или пиксели) снапается в один из трёх холстов: **1:1**, **16:9**, **9:16**.

| Вход | Холст листа и каждой клетки |
|---|---|
| 1:1 | 1:1 |
| 16:9, 4:3, 3:2 | 16:9 |
| 9:16, 3:4, 2:3 | 9:16 |

`POST /api/generate` пишет этот aspect в job. Промпт требует 2×2 на этом холсте без letterbox. Нарезка без изменений: `floor(W/2)×floor(H/2)` сохраняет ratio клетки.

## Не делаем

- Четыре отдельных job
- Отдельная сетка 1×4 / 4×1
- Измерение файла на каждом poll
