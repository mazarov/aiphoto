## Экономика (та же, что SSOT)

Пока нет mature D30:

```text
CAC_max = 82 ₽
ценность цели purchase, если поле обязательное = 229 ₽
нужная конверсия ≈ CPC / 82
CPC > 20 ₽ → learning loss, в оплату уже >24%
```

P&L считать скиллом `@direct-daily-pnl`: выручка = наши чеки, генерация = начисленные кредиты × 0,5 ₽, реклама = Reports API без НДС × 1,22.

## Launch gate

Включать только если:

1. Выбран вариант бюджета A/B/C.
2. Код из раздела выше на проде.
3. MP живой: новые оплаты пар с `yandex_conversion_sent_at`.
4. UTM на черновике: `utm_campaign={campaign_id}`, не сломанный URL как у ПРОМТЫ-ДР до фикса.
5. Прогноз CPC по фразам; для CPC > 20 ₽ — явный допуск learning loss.
6. Стратегию ДР на этой календарной неделе не меняли.

Stop-loss (те же пороги SSOT):

- фраза 82 ₽ без покупки — стоп фразы
- кампания 164 ₽ без покупки — стоп кампании
- ГЕНЕРАЦИЯ: 30 кликов без успешной генерации — стоп группы
- ПРОМТЫ: генерации нет как обязательный шаг; 30 кликов без checkout — диагностика посадки, не «долить»
- CAC медиа > 82 ₽ при ≥5 плательщиках — не масштабировать

Масштаб пар: ≥5 первых плательщиков **этого** кластера, CAC ≤ 82, mature D30, шаг 20–30% не чаще раза в 3 дня.
