## Подстановка из CSV

| Плейсхолдер | Колонка CSV | Пример |
|---|---|---|
| `{имя}` | `display_name` | если пусто — писать «Здравствуйте!» без имени |
| `{пакет}` | `plan` → человекочитаемое имя | `trial` → Проба, `start` → Старт, `pro` → Про, `max` → Максимум |

## План → название пакета

- `trial` → Проба
- `start` → Старт
- `pro` → Про
- `max` → Максимум
