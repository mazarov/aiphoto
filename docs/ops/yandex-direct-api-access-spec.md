# PromptShot — доступ к API Яндекс Директа

**Продукт:** PromptShot (`https://promptshot.ru`)  
**Назначение API:** только чтение статистики своих поисковых кампаний.

## Что делает приложение

Ежедневный внутренний P&L рекламы:

- расход кампаний (поле «Расход», без изменения ставок и объявлений);
- поисковые запросы с расходом — для минус-фраз;
- сверка с нашими оплатами (не с полем «Доход» в кабинете).

Интерфейс для команды: отчёт в Cursor (таблица выручка / касса / налог / генерация / реклама с НДС). Пользователи сайта API Директа не видят и не вызывают.

## Какие методы

JSON API v5, read-only:

- `Reports`: `CAMPAIGN_PERFORMANCE_REPORT`, `SEARCH_QUERY_PERFORMANCE_REPORT`
- `Campaigns.get` — список своих кампаний для проверки токена

Запись, модерация, смена стратегии, ставки, объявления — не используются.

## Кампании

## Стек

Node.js 20, `fetch`, без SOAP и без стороннего SDK Директа.
