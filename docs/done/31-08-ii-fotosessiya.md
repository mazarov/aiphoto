# 31-08 Гибридный SEO-хаб «ИИ фотосессия»

> **Дата:** 2026-08-31
> **Обновлено:** 2026-09-02 (Title/H1 complement on L1/L2 rolled back)
> **Статус:** реализовано
> **Ветка:** `feature/31-08-ii-fotosessiya`
> **Роль:** `@senior-seo-strategist-ru`

`/ii-fotosessiya` — единый владелец коммерческого кластера «ИИ фотосессия
по фото» и информационного кластера «промты для ИИ фотосессии». Отдельный
индексируемый `/promty-dlya-ii-fotosessii` не возвращаем, на главную его не
перенаправляем.

---

## 1. Владельцы интентов

- `/ii-fotosessiya` — ИИ-фотосессия по фото + готовые промты для
  ИИ-фотосессии.
- `/ii-fotosessiya/{scenario}` — генерация и промты конкретного сценария.
- `/` — широкий кластер «промты для фото», без H2-владельца
  «готовые промты для ИИ фотосессии».
- L1/L2 каталога (`/promty-dlya-foto-par` и др.) — ключ кадра в Title/H1,
  без complement «и ИИ фотосессии». Хвост фотосессии только в intro/H2/FAQ.
- `/generaciya-foto` — создание одного фото, не серии.

---

## 2. 301

- `/promty-dlya-fotosessii` → `/ii-fotosessiya`
- `/promty-dlya-ii-fotosessii` → `/ii-fotosessiya`
- `/promty-dlya-ii-fotosessii/:slug` → `/ii-fotosessiya/:slug`
- Редиректа старого хаба на `/` нет.

---

## 3. Хаб

- Title: `ИИ фотосессия по фото онлайн — готовые промты | PromptShot`.
- H1: `ИИ фотосессия по фото`.
- В hero — прямой CTA `Загрузить фото`.
- После сценариев — H2 `Промты для ИИ фотосессии на русском`.
- Сервер рендерит до шести уникальных русских промтов с карточками,
  копированием и ссылками на полный пример.
- После промтов: HowTo, галерея серий, тарифы и FAQ.
- Не обещать бесплатную генерацию или работу без регистрации.

---

## 4. Дочерние страницы

- H1 сохраняет сервисный ключ: женская, мужская, парная и другие
  ИИ-фотосессии.
- Title дополняется фразой `готовые промты`.
- У каждого сценария уникальный H2 промтов и индексируемые тексты.
- В листинг попадают только опубликованные серии фотосессии, одновременно
  соответствующие SEO-тегу сценария.
- L2 индексируется и попадает в sitemap при наличии минимум восьми таких серий.

---

## 5. Источник карточек

- Source of truth — завершённые `landing_generations.edit_kind=photoshoot`.
- Fallback — опубликованный web UGC, распознанный как многофайловая
  фотосессия.
- Обычные одиночные Telegram-карточки не используются в галерее,
  промтах и коллажах этого кластера.
- Enrich и `.in(id)` идут GET через OpenResty: списки режутся на 40 id
  (`POSTGREST_IN_CHUNK`), иначе 414/502 на хабе.

---

## 6. Главная и перелинковка

- Главная сохраняет Title/H1 широкого каталога промтов для фото.
- FAQ главной даёт индексируемую ссылку `Промты для ИИ фотосессии` на
  `/ii-fotosessiya`.
- Точная H2-формулировка фотосессии удалена с главной.
