# 01-09 — Remix: сохранить промпт, генерировать отдельно

> Дата: 2026-09-01
> Ветка: `feature/01-09-remix-save-only`
> Поверхность: generate-dock prompt sheet (`CardInlineGeneratePanel`)

## Цель

После «Что изменить?» CTA больше не тратит кредиты. Кнопка только **Сохранить**: переписать промпт. Генерация — отдельным «Создать фото».

## Решения

| # | Решение |
|---|---|
| D1 | Шторка remix: `Сохранить` / `Сохраняем…`. Не `Применить и сгенерировать` |
| D2 | Успех remix пишет `draftPrompt`, чистит поле правки, закрывает шторку. `POST /api/generate` не вызывается |
| D3 | Без готового кадра дальше обычный footer «Создать фото» |
| D4 | С готового кадра после save rail primary = «Создать фото» (local edit с сохранённой правкой). «Что изменить» снова открывает шторку после генерации |
| D5 | `/foto-v-promt` PromptRemixWidget не трогаем |

## Вне scope

- Новый API
