Динамика P1 → P3:

| Семья | Показы/д | CTR | Клики/д | Позиция |

| картинка / изображение | 29,6 → 43,3 | 18,0% → 16,9% | 5,3 → 7,3 | 5,6 → 4,3 |

**«По описанию».** Спрос в 3,6 раза выше, чем у «по промту», позиция хуже на 5,5 пункта. Появление фразы в Title 02.09 сузило выдачу: показов втрое меньше, CTR вчетверо выше, кликов даже чуть больше. Но позиция 8,8 — низ первой страницы.

Причина — фраза нигде не стоит непрерывно. В Title «по фото **или** описанию», в Description «по своему снимку **или** описанию», в H1 слова нет вообще. Единственные непрерывные вхождения:

```
generatorTitle: "Создать фото по описанию или промту",   ← строка не рендерится
    title: "Фото по описанию",                            ← карточка в «Что ещё умеет»
 "Можно ли сгенерировать фото по описанию?",              ← вопрос FAQ
```

**«Картинка / изображение» — дыры нет.** По августовскому снапшоту казалось иначе; свежие данные дают CTR 16,7% и позицию 5,6 → 4,3. Правок не требует.

### Почему шаблон слабый

Мета всех 22 страниц собирается одной функцией `scenarioHero()` в `generaciya-foto-scenario-copy.ts`:

```
metaTitle: `${metaTitleBase} | PromptShot`
metaDescription: `${h1Base} по промту или снимку. Выберите образ, загрузите фото — нейросеть PromptShot без фотографа.`
```

Description открывается дословным повтором `h1Base`, который уже стоит в Title. В выдаче для `na-den-rozhdeniya`:

> **Сделать ИИ фото на день рождения | PromptShot**
> Сделать ИИ фото на день рождения по промту или снимку. Выберите образ, загрузите фото — нейросеть PromptShot без фотографа.

Одна фраза дважды, дальше инфинитив вместо предложения, ни одной причины кликнуть. Вторая половина побайтово одинакова на 22 страницах.

- `/generaciya-foto?payment=8540c6ae-…` — 65 показов, идентификатор платежа проиндексирован как страница.

Заготовка для №2 (`introLead` уже задан на каждый слог, новый контент не нужен):

```
metaDescription: `Готовые образы ${introLead}: загрузите свой снимок или опишите кадр — результат без студии.`
```

Для дня рождения — 125 знаков, в лимит ≤132 проходит. Стоит добавить число карточек темы: цифра в сниппете отличает от конкурентов, а у детей она есть (индексируются при 8+ карточках).

## 9. Решено не делать

- **Откат Title хаба от 02.09.** Вреда в данных нет: показы и клики выросли, позиция не изменилась.
- **Правки под «картинка / изображение».** CTR 16,7%, позиция улучшилась с 5,6 до 4,3.
- **«Бесплатно» в Title / Description.** Семья крупнейшая (спрос 1 262/д, CTR 16,8%, клики 9,5 → 22,4/д), но бесплатно только **копирование промта**, генерация — нет. Правило `seo-copywriter-ctr-ru` запрещает обещать бесплатное в сниппете.
- **Погоня за короткими головами копирайтом.** «ии фото» — спрос 1 270/д при позиции 15,9; это вопрос стратегии URL.

## 10. Открытые вопросы

1. **FAQ обещает то, чего нет.** При «генерация не бесплатна» два видимых ответа на `/generaciya-foto` утверждают обратное: «после входа есть тестовые запуски» (вопрос про промт бесплатно) и «Бесплатные тестовые генерации помогают оценить возможности сервиса» (вопрос про водяной знак). Нужно решить: убрать формулировки или подтвердить, что тестовые запуски существуют.

2. **Владелец `промты для генерации картинок`.** Спрос есть, ключ смешивает «промты» (владелец — `/`) и «генерацию» (владелец — эта страница). Сейчас не принадлежит никому.

3. **`/pricing` закрыт в `robots.txt`**, но FAQ хаба ссылается на него трижды. Внутренние ссылки уходят на страницу, которую робот не обойдёт.

4. **`ии фотосессия мужские бесплатно по фото онлайн`** — 55 показов, 0 кликов, позиция 9,7 на хабе. Запрос кластера `/ii-fotosessiya`, приземляется сюда.

5. **Дети без показов:** `v-zerkale`, `s-mamoy`, `cherno-beloe`, `s-dochkoy`, `kollazh` дают 0 кликов. Проверить supply карточек и порог индексации (8+).
