# SEO вотчлист страниц

Ветка реализации: `feature/21-08-seo-page-watchlist` (если дерево занято чужим WIP — новые файлы кладутся в текущий checkout, коммит не смешивать).

## Решение

- Вотчлист: **топ-30 URL** (~89% показов за 14.07–14.08.2026).
- Экран как в кабинете Вебмастера: строка URL → раскрытие запросов.
- Зерно: Webmaster `query-analytics` (окно ~14 дней). Не группы кабинета и не enhanced-export.

## Данные

| Поле | Откуда |
|---|---|
| URL, показы, клики, CTR, позиция по дням | `text_indicator=URL` |
| Запросы страницы + спрос | `text_indicator=QUERY` + `TEXT_MATCH` по path, страницы по 20, до 100 запросов |
| Δ | вторая половина окна минус первая |

В список попадают только запросы, у которых complementary URL = эта страница (`/` иначе матчит весь сайт). Потолок метода 20 строк/вызов — refresh крутит offset до 100. Сумма запросов меньше итога URL: хвост не влезает. Обновление: `node src/standalone/refresh-seo-watchlist.mjs` (OAuth в `.cursor/yandex-seo.env`). Снимок: `landing/src/data/seo-watchlist-snapshot.json`.

## Экран

- `/admin/seo` + `GET /api/admin/seo-watchlist`
- Allowlist тот же: `ANALYTICS_ADMIN_EMAILS`
- SSOT путей: `landing/src/data/seo-watchlist-paths.json`
- Фильтр дней: пресеты «Все / 7 дней / 1 день» + даты с–по. Цифры и Δ пересчитываются по выбранному окну (Δ = такое же число дней сразу до фильтра).
- Под запросом: график показов, спроса, кликов, CTR и позиции на одном SVG. Скрыт по умолчанию, раскрывается кликом по запросу.
- Сортировка смапленных запросов: по показам (дефолт) или по кликам. Над таблицей — покрытие показов/кликов относительно итога URL.
