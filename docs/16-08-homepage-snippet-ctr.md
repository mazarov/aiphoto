# 16-08 Homepage snippet CTR

> Дата: 2026-08-16  
> Статус: тексты внесены в код, ждём замер через 14 дней  
> Ветка: `feature/16-08-homepage-snippet-ctr` → `main`

Переписать сниппет и SEO-блоки главной `promptshot.ru/`, чтобы поднять CTR на релевантных запросах и не испортить ядро.

## Зачем

Главная даёт ~29% поисковых кликов Яндекса. Дневной темп к пику 29.07–11.08 просел примерно на **71 клик/день**. Ядро («промты», «промты для фото») не упало. Просели чужие показы: Яндекс показывает `/` по запросам, где сниппет не отвечает на интент, и CTR там 0–5%.

Цель не «налить показы», а **поднять CTR на релевантных запросах** и не испортить ядро.

Три URL объясняют ~77% измеренного разрыва: `/`, `/promty-dlya-foto-par`, `/promty-dlya-semejnogo-foto`. Этой правкой лечим только главную. Пары и семью не трогаем.

«Идеи / пример» — слабо, не приоритет.

Яндекс не назначает блок запросу сам. Он вытягивает фрагмент, где есть слова запроса. Поэтому ядро и слабый CTR **не мешать в одном абзаце**. Сейчас `intro` всё склеивает — его надо переписать, иначе схема не сработает.

Живая выдача 16.08.2026, Москва (`lr=213`): сниппет главной = Title + Description; по «бесплатные…» Яндекс иногда тянет `intro`, не meta description.

## Что меняем

Только тексты главной `promptshot.ru/`:

- Title
- H1
- meta description
- подзаголовок героя
- intro под каталогом
- H2 и текст блока «Каталог промтов»

Код:

- `landing/src/lib/homepage-seo-copy.ts` — Title, description, h1, heroSubtitle, intro, examplesTitle, examplesIntro + новое поле `examplesIntroSecondary` (Текст 2)
- `landing/src/components/home/HomepageExamplesExplorer.tsx` — второй абзац под H2; лейбл `Каталог промтов` уже был целевым
- `landing/src/components/HomeSeoBlocks.tsx` — intro рендерится из константы, правок кода не потребовалось; FAQ не трогали
- `landing/src/app/page.tsx` — H1 = `h1.main` + `h1.accent`, правок кода не потребовалось

FAQ про фотосессию, бесплатность и нейросети не ломаем.

## Согласованный угол

Не «скопируй в нейросеть» в Title (слабо, повторяет «в ИИ»).  
Не «50 идей» (мы каталог, не статья).

Лучший угол: **промты с примерами результата** — на странице сетка фото, у конкурентов в топе списки без живого каталога.

## Целевые тексты

Было в коде до правки (`homepage-seo-copy.ts`):

- Title: `Промты для фото ИИ — готовые промты для нейросетей | PromptShot`
- Description: `Готовые промты для фото и промты для ИИ-фотосессии в Nano Banana и других нейросетях. …`
- H1: `Промты для фото` + `и ИИ-фотосессии в нейросетях`
- Intro склеивает «готовые / фотосессии / Nano Banana / бесплатно / на русском»

Ставим:

**Title**  
`Промты для фото в ИИ с примерами | PromptShot`

**H1**  
`Промты для фото` + акцент `в ИИ`

**Подзаголовок**  
`Выберите понравившийся результат, откройте карточку и используйте промт для своего фото.`

**Description**  
`Каталог готовых промтов для фото: пары, семья, портреты и другие категории. Все тексты на русском — копируйте и используйте бесплатно.`

**Блок 2**

- Лейбл: `Каталог промтов`
- H2: `Готовые промты для ИИ-фотосессии`
- Текст 1: `Выберите пример для пары, семьи или портрета и откройте карточку с готовым промтом для фото.`
- Текст 2: `Все промты написаны на русском. Их можно бесплатно скопировать и вставить вместе со своим фото в ChatGPT, Gemini, Nano Banana или другую нейросеть.`

Транслит-синонимы («гпт, джипити», «нано банана, нанобанана», «гемини») из старого `examplesIntro` убраны: в блоке 2 остались только ChatGPT, Gemini, Nano Banana латиницей. «Нано банана» кириллицей остаётся в FAQ.

**Intro** (чтобы не перебивал сниппеты)  
`PromptShot — каталог промтов для фото в ИИ. Откройте карточку и скопируйте текст в нейросеть.`

## Чего не делать

- Не оптимизировать главную под «бесплатные» и «на русском» в Title.
- Не обещать «50 сценариев», если на странице лента карточек.
- Не ждать, что сниппет закроет −71 клик/день. Ожидание: ядро не упало + средняя корзина чуть лучше, ориентир **+5–10 кликов/день**.
- Семью и пары этой правкой не лечим — у них свои URL.

## Как понять, что сработало

Через 14 дней в Вебмастере по `/`:

- клики главной в день не ниже текущих;
- CTR и позиция «промты для фото» / «промты» / «промты для ии» не просели;
- CTR «готовые промты для фото» и «промты для ии фотосессии» можно расти;
- показы «фотосессии» могут чуть сесть — нормально, если клики главной держатся.

Если ядро просядет по позиции — откатить Title, оставить description и блок 2.
